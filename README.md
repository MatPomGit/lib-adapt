# Adaptive Control and Stability Monitoring

Experimental Kotlin/JVM library for threshold-based stability monitoring, consecutive qualifying updates, timeout and invalidation. Author: Mateusz Pomianek. No clinical validation or participant allocation.

JDK 17, Gradle 9.6.0: `gradle test jar`. Local Maven-format artifacts: `gradle publishMavenJavaPublicationToBuildRepository`. See [API contract](contracts/api.json). No remote publication. Historical study-specific snapshots are not included in the JAR. Repository-wide license clearance remains open.
